## 🚀 快速开始

### 环境要求

- Node.js 22+（建议使用当前 LTS）
- pnpm (推荐) / npm / yarn

### 安装

```bash
# 克隆项目
git clone https://github.com/Moyuin-aka/tyndall-public
cd tyndall-public
# 安装依赖
pnpm install

# 可选：配置自己的在线服务；不填凭据也可浏览示例站点
cp .env.example .env

# 启动开发服务器
pnpm dev  # 访问 http://localhost:4321

# 生产构建
pnpm build

# 预览构建结果
pnpm preview
```
